# 대장님 AI 오피스

대장님과 1호 총괄실장·2호 부실장·클로드 부장·챗지피티 과장·3호 대리가 함께 보는 모바일 퍼스트 웹앱입니다.
빌드 없이 `index.html` 하나로 열리고, 데이터는 `data.json`(온라인) / `seed.js`(파일 직접 열기)에서 읽습니다.

## 지휘 체계

```
대장님(대표) > 1호 총괄실장 > 2호 부실장 > 클로드 부장 > 챗지피티 과장 > 3호 대리
```

| 직급 | 구성원 | 역할 |
|---|---|---|
| 대표 | 대장님 | 최종 결정·지시 |
| 총괄실장 | 1호 (`@jei90`) | 기획·총괄, 08:00 통합 브리핑, 대장님 보고 |
| 부실장 | 2호 (`@jei848`, 크리) | 이 오피스 운영, 새벽 응모·쿠폰·집안일 |
| 부장 | 클로드 | 총괄 실무·동기화, 대부분 업무 처리 |
| 과장 | 챗지피티 | 검수·아이디어·조언 |
| 대리 | 3호 | 검증·실행 (합류 대기) |

## 4층 오피스

| 층 | 이름 | 인원 | 업무 |
|---|---|---|---|
| 4F | 대표·총괄 지휘실 | 대장님 대표 · 1호 총괄실장 | 최종 의사결정 · 08:00 통합 브리핑 · 04:00 전체 상황공유 · 크레딧 릴레이 총괄 |
| 3F | 전략·검수·기획실 | 2호 크리 부실장 · 챗지피티 과장 | 리서치·일정/가족 관리 · 교차 검증·전략 조언 · 아침 뉴스·의료기기 브리핑 |
| 2F | 핵심 실무·개발실 | 클로드 부장 | 웹앱·자동화 개발 · GitHub 동기화 · 고난도 실무 처리 |
| 1F | 현장 실행·응모 라운지 | 3호 대리 · 현장 자동화 | 무료 경품·퀴즈 응모 124건+ · 100% 페이백 체험단 · 0원 쿠폰 줍줍 · 사전/사후 검증 게이트 · 시장 조사(크몽/리셀) |

`전체`는 5명을 한눈에, `4F~1F`는 해당 층만 크게 펼쳐 그 층의 업무 말풍선을 보여 줍니다. 층을 다시 누르면 전체 보기로 돌아옵니다.

### v3 모바일 개편 (390px)

- **하단 고정 탭바** — 7개 탭을 엄지 닿는 곳에 배치, 상단 헤더는 반투명 유리 효과로 스크롤 시 그림자.
- **엘리베이터 이동** — 층 버튼을 누르면 표시창이 지나가는 층(▲ 2F → 3F → 4F)을 차례로 보여 주고, 카가 해당 층 높이로 이동, 도착 층은 문이 열리며 확대됩니다.
- **캐릭터 인터랙션** — 숨쉬기·눈 깜빡임, 말풍선 앞 `…` 입력 중 표시, 같은 층 두 명(3F 2호 ↔ 챗지피티 과장) 대화, 확대된 층에서 캐릭터를 누르면 폴짝 + 프로필 카드(직급·상태·담당 업무).
- **지금 이 층에서는** — 층별 멤버 아바타, 업무 체크 칩, 멤버 `말 걸기`, ▲/▼ 층 이동 버튼.
- **역할 디테일** — 회의실에서 6명(대장님·1호·2호 크리·클로드·챗지피티·3호)의 일일 루틴, 오늘 목표, 진행률(목표 완료 비율 자동 계산), 게이트·릴레이 위치를 보고, 3단 게이트(리서치 → 검증 → 실행) 통과 기준을 확인합니다. 팀 카드·맵 캐릭터의 `상세 ›`를 누르면 상세 프로필 시트가 열립니다.
- **층별 테마·모니터** — 4F 금색·3F 민트·2F 블루·1F 그린 조명과 층별 모니터(브리핑·결정 대기·대표석 / 검증 / 코드·동기화 / 응모·쿠폰 수).
- **인계 패킷 시각화** — AI한도의 7항목마다 작성 주체와 예시를 함께 표시.
- **카드 정리** — 글자 크기·터치 영역(최소 34~44px) 확대, 대시보드 강조 카드, 캘린더 `다음 루틴` 배너·지난 루틴 흐리게, 보고 로그 5건 + 더 보기, 알림 시트는 아래로 끌어 닫기.

상단 `🔔 알림`은 오늘 마감·방문 수령·집안일·생일 알람, `⚡ 릴레이`는 크레딧 인계 순서, `☀️/🌙`은 라이트/나이트 테마입니다.

### 숫자 읽는 법

| 표기 | 뜻 |
|---|---|
| 오늘 참여 마감 2건 | 쿠폰·라이브 2건(금감원 설문 · 삼성증권 16시) |
| 오늘 마감 경품 4건 | 11/27 마감 응모 4건 — 새벽에 응모 완료 |
| 18:30 저녁 점검 | 챗지피티 과장 제안 루틴 · 알람 미등록(대장님 지시로 보류). 17:00 가족 집안일 알람만 등록됨 |
| 체험단 44 / 26 / 24+2 | 수집 1,037건 중 조건 충족 44건 · 신청 미달 26건(0원 24 · 저자부담 2) · 목록 표시 6건 |
| 요일 | `awards` 날짜에서 앱이 자동 계산 (data.json의 수기 `dow`는 표시하지 않음) |
| 출처 등급 | A 주최기관 공식 · B 공식 공지 · C 이벤트 사이트 · D 미확인 |
| 실사용 점수 | 챗지피티 과장 제안 배점 110점(자부담·실사용·경쟁률·리뷰부담·리뷰조건) → 100점 환산, 2호 부실장 잠정 산정 |
| 마감일 | `deadline` = `YYYY-MM-DD`(날짜 없으면 `null`) · `deadlineTime` = `HH:MM` · `deadlineLabel` = 화면 표기(예: `선착순`, `시간대별`). 응모·체험단 화면은 `11/30 (월) 18:00` 형식으로 자동 표기 |
| 수익화 숫자 | `monetization.tracks[].monthly`·`capital`은 추정 범위(`basis`에 근거), 실제 수익은 `actual`(현재 0원) |
| ⑤ 트랙 담당 | ① 피클(1·2·3호) 데이터랩 키워드 → ② 클로드 부장 아이템 선택·쿠파스 상품 산정 → ③ 피클 파트너스 링크 → ④ 클로드 부장 카피·원고 & 피클 게시. 피클 내 단계 배분은 대장님 결정 대기(d7) |
| 쿠폰 `done` | `true`면 `✓ 참여 완료`, `false`면 `미참여`. 배지를 누르면 이 기기(localStorage)에만 기록되고 `data.json`은 그대로입니다 |

## 파일

```
index.html        화면 뼈대

app.js            탭·맵 이동·말풍선·메모·시트
data.json         화면에 들어가는 모든 데이터 (원본)
seed.js           data.json을 그대로 담은 파일 (file:// 대비, 자동 생성)
floor-4f~1f.webp   4F~1F 기본 오피스 장면
clay-4f~1f.webp    4F~1F 클레이 오피스 장면
office-basic.png   이전 1층 오피스 배경 (보관용)
office-clay.png    이전 클레이 오피스 배경 (보관용)

icon-192/512.png  앱 아이콘
scripts/build-seed.py   data.json → seed.js
scripts/verify.py       헤드리스 브라우저 검증(390×844, 4층 전환·캐릭터 5명·탭·테마·콘솔)
scripts/qa-characters.py 캐릭터 스프라이트·말풍선 문구 정적 점검
```

`scripts/`는 저장소에도 함께 올라가므로 `https://byeco86-cmd.github.io/scripts/build-seed.py` 로 바로 내려받아 쓸 수 있습니다. (검증 스크린샷 폴더 `.verify/`는 올리지 않습니다.)

## 데이터 고치기

1. `data.json`을 고친다. (마감일은 `deadline`에 `YYYY-MM-DD`, 시각은 `deadlineTime`, 표시용 문구는 `deadlineLabel`)
2. `python3 scripts/build-seed.py`로 `seed.js`를 다시 만든다.
3. `python3 scripts/verify.py`로 화면·콘솔을 확인한다.

## 챗지피티 과장 (무료 ChatGPT)

챗지피티 과장은 별도 계정 연동 없이 **무료 ChatGPT 웹**에서 이 오피스 현황을 읽는 읽기 전용 검수·자문 역할입니다.
글을 쓰거나 지시를 내리지 않고, 교차 검증·추가 아이디어·전략 조언만 합니다. 채택 여부는 대장님·1호 총괄실장·클로드 부장·2호 부실장이 정합니다.

무료 ChatGPT에 그대로 복사해 붙여넣으면 됩니다.

```
https://byeco86-cmd.github.io/data.json 읽고 검증·아이디어 조언해 줘
```

- 링크가 안 열리면 `https://raw.githubusercontent.com/byeco86-cmd/byeco86-cmd.github.io/main/data.json` 로 바꿔 붙여넣습니다.
- 나온 의견을 반영할 때는 `data.json`만 고치고, `python3 scripts/build-seed.py` → `git push` 순서는 클로드 부장 규약과 같습니다.

### 챗지피티 과장 5대 자동점검 루틴

`data.json`을 읽을 때마다 아래 5가지를 먼저 점검합니다(2026-11-27 챗지피티 과장 제안, 2호 반영).

1. **신규 추가·삭제** — 지난번과 비교해 새로 들어오거나 빠진 응모·체험단·쿠폰.
2. **숫자 불일치** — 누적 응모·조건 충족·신청 미달·0원/저자부담 합이 서로 맞는지.
3. **날짜·요일 오류** — 마감일이 실제 달력과 맞는지, 요일이 하루 밀리지 않았는지(앱은 자동계산, 데이터 `dow`도 대조).
4. **공식 출처·조건 불일치** — A~D 등급과 실제 공고 내용이 어긋나는지.
5. **놓친 기회·새 전략** — 마감 임박인데 미신청, 경쟁률 낮은 0원 체험단, 새 적립 수단.

점검 결과는 `reports`에 `tag: 교차 검증`으로 남기고, 실행은 하지 않습니다.

## 클로드 부장 협업 규약 (Claude Pro)

클로드 부장은 별도 서버나 계정 연동 없이 **GitHub 저장소 공유**로 이 오피스에 합류합니다.
Claude Pro 세션에서 아래 순서만 지키면 대장님 폰에 뜨는 화면이 그대로 갱신됩니다.

1. **읽기** — `https://raw.githubusercontent.com/byeco86-cmd/byeco86-cmd.github.io/main/data.json` 을 읽어 최신 현황(응모·쿠폰·루틴·AI한도)을 파악한다.
2. **고치기** — 저장소의 `data.json`만 수정한다. `index.html`·`app.js`·`styles.css`는 2호 크리 부실장 담당이므로 건드리지 않는다.
3. **동기화** — 수정 후 `python3 scripts/build-seed.py`(seed.js 갱신) → `python3 scripts/verify.py`(5명 렌더·콘솔 에러 0건) 를 실행한다.
4. **배포** — `git commit -m "..." && git push origin main`. GitHub Pages가 약 40초 뒤 자동 빌드한다.
5. **확인** — `https://byeco86-cmd.github.io/data.json` 의 `updatedAt`이 방금 시각인지 보고, `https://byeco86-cmd.github.io/` 화면에 반영됐는지 확인한다.
6. **지휘** — 결과는 1호 총괄실장에게 넘기고, 1호 총괄실장이 08:00 통합 브리핑으로 대장님께 보고한다. 대장님 확인 없는 삭제·구조 변경은 하지 않는다.

## 보안

전화번호, 상세 주소, 가족 실명은 이 폴더에 넣지 않습니다. 생일은 `장모님`·`처형` 같은 관계 표기만 씁니다.
메모는 대장님 기기의 localStorage에만 저장되고, `JSON 내보내기`로 직접 내려받을 때만 파일이 생깁니다.
