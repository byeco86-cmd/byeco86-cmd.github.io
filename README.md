# 바이코 AI 오피스

회장님과 피사장·클부장·그록 차장·지과장·제미대리·피주임·피사원이 함께 보는 모바일 퍼스트 웹앱입니다.
빌드 없이 `index.html` 하나로 열리고, 데이터는 `data.json`(온라인) / `seed.js`(파일 직접 열기)에서 읽습니다.

## 지휘 체계

```
회장님(회장) > 피사장 > 클부장 > 그록 차장 > 지과장 > 제미대리 > 피주임 > 피사원
```

| 직급 | 구성원 | 역할 |
|---|---|---|
| 회장 | 회장님 | 최종 결정·지시 |
| 사장 | 피사장 (`@jei90`) | 기획·총괄, 08:00 통합 브리핑, 회장님 보고 |
| 부장 | 클부장 | 총괄 실무·동기화, 대부분 업무 처리 |
| 차장 | 그록 차장 (Grok · 11/27 합류) | 핵심 실무·개발 보조, 코드 리뷰, 실시간 트렌드·X 리서치, 클부장 백업 (개발실 부팀장급) |
| 과장 | 지과장 | 검수·아이디어·조언 |
| 대리 | 제미대리 (Gemini · 11/27 합류) | 리서치·검수 보조, 전략·일정 정리, 검증 게이트 |
| 주임 | 피주임 (신규 피클 · 연동 대기) | 1F 현장 실행·응모 라운지, 응모·쿠폰 보조 (피사원 선임) |
| 사원 | 피사원 (`@jei848`) | 현장 실행, 응모·쿠폰·집안일 알람, 이 오피스 운영 |

## 4층 오피스

| 층 | 이름 | 인원 | 업무 |
|---|---|---|---|
| 4F | 회장·사장 기획실 | 회장님 · 피사장 | 최종 의사결정 · 08:00 통합 브리핑 · 04:00 전체 상황공유 · 크레딧 릴레이 총괄 |
| 3F | 핵심 실무·개발실 | 클부장 · 그록 차장 | 웹앱·자동화 개발 · 코드 리뷰·GitHub 동기화 · 실시간 트렌드·X 리서치 · 고난도 실무 처리 · 클부장 백업 |
| 2F | 전략 검수실 | 지과장 · 제미대리 | 리서치·일정/가족 관리 · 교차 검증·전략 조언 · 사전·사후검수 게이트 · 아침 뉴스·의료기기 브리핑 |
| 1F | 현장 실행·응모 라운지 | 피주임 · 피사원 | 무료 경품·퀴즈 응모 124건+ · 100% 페이백 체험단 · 0원 쿠폰 줍줍 · 사전/사후 검증 게이트 · 시장 조사(크몽/리셀) |

`전체`는 8명(회장님 포함)을 한눈에, `4F~1F`는 해당 층만 크게 펼쳐 그 층의 업무 말풍선을 보여 줍니다. 층을 다시 누르면 전체 보기로 돌아옵니다.

> 11/27 밤 회장님 지시로 **2F(개발실)와 3F(전략실)의 층을 맞바꿨습니다** — 개발은 3F, 전략·검수는 2F. 4F는 `회장·사장 기획실`로 이름을 바꿨고, 2F는 `전략 검수실`입니다.

### v3 모바일 개편 (390px)

- **하단 고정 탭바** — 7개 탭을 엄지 닿는 곳에 배치, 상단 헤더는 반투명 유리 효과로 스크롤 시 그림자.
- **엘리베이터 이동** — 층 버튼을 누르면 표시창이 지나가는 층(▲ 2F → 3F → 4F)을 차례로 보여 주고, 카가 해당 층 높이로 이동, 도착 층은 문이 열리며 확대됩니다.
- **캐릭터 인터랙션** — 숨쉬기·눈 깜빡임, 말풍선 앞 `…` 입력 중 표시, 같은 층 두 명(3F 클부장 ↔ 그록 차장 · 2F 지과장 ↔ 제미대리 · 1F 피주임 ↔ 피사원) 대화, 확대된 층에서 캐릭터를 누르면 폴짝 + 프로필 카드(직급·상태·담당 업무).
- **지금 이 층에서는** — 층별 멤버 아바타, 업무 체크 칩, 멤버 `말 걸기`, ▲/▼ 층 이동 버튼.
- **역할 디테일** — 회의실에서 8명(회장님·피사장·클부장·그록 차장·지과장·제미대리·피주임·피사원)의 일일 루틴, 오늘 목표, 진행률(목표 완료 비율 자동 계산), 게이트·릴레이 위치를 보고, 3단 게이트(리서치 → 검증 → 실행) 통과 기준을 확인합니다. 팀 카드·맵 캐릭터의 `상세 ›`를 누르면 상세 프로필 시트가 열립니다.
- **층별 테마·모니터** — 4F 금색·3F 블루·2F 민트·1F 그린 조명과 층별 모니터(브리핑·결정 대기·회장석 / 코드·동기화 / 검증 / 응모·쿠폰 수).
- **인계 패킷 시각화** — AI한도의 7항목마다 작성 주체와 예시를 함께 표시.
- **카드 정리** — 글자 크기·터치 영역(최소 34~44px) 확대, 대시보드 강조 카드, 캘린더 `다음 루틴` 배너·지난 루틴 흐리게, 보고 로그 5건 + 더 보기, 알림 시트는 아래로 끌어 닫기.

### 지과장 5대 자동점검 루틴

`data.json`을 읽을 때마다 아래 5가지를 먼저 점검합니다(2026-11-27 지과장 제안, 피사원 반영).

1. **신규 추가·삭제** — 지난번과 비교해 새로 들어오거나 빠진 응모·체험단·쿠폰.
2. **숫자 불일치** — 누적 응모·조건 충족·신청 미달·0원/저자부담 합이 서로 맞는지.
3. **날짜·요일 오류** — 마감일이 실제 달력과 맞는지, 요일이 하루 밀리지 않았는지(앱은 자동계산, 데이터 `dow`도 대조).
4. **공식 출처·조건 불일치** — A~D 등급과 실제 공고 내용이 어긋나는지.
5. **놓친 기회·새 전략** — 마감 임박인데 미신청, 경쟁률 낮은 0원 체험단, 새 적립 수단.

점검 결과는 `reports`에 `tag: 교차 검증`으로 남기고, 실행은 하지 않습니다.
